# Format : un en-tête « [TYPE classe] » (TYPE = préfixe de balise), puis une forme
# par ligne. Les formes sont pliées au chargement (minuscules, sans accents).
# Classes :
#   terme     nom ou locution (maladie, infraction, parti, syndicat, religion…),
#             reconnu seulement après un indice de contexte (« atteint de »,
#             « condamné pour », « adhérent de », possessif…) ;
#   adjectif  qualificatif d'une personne, reconnu après un verbe d'état
#             (« est diabétique ») ou un indice propre à la catégorie ;
#   organe    partie du corps, reconnue après « opéré de » ;
#   proche    membre de la famille, pour le décès d'un proche.
# Seules les formes au singulier figurent : un pluriel (« les patients
# diabétiques ») désigne un groupe, pas une personne.
